## 🚀 Getting Started

### Prerequisites
- Java JDK 8 or above
- Any IDE (IntelliJ IDEA, Eclipse, VS Code) or terminal

### Run a program
```bash
# Compile
javac Hello.java

# Run
java Hello
```

## 🧠 Concepts at a Glance

**Control Flow**
- `if-else`, `switch` statements

**Loops**
- `for`, `while`, `do-while`, nested loops

**Arrays**
- 1D arrays, 2D/multi-dimensional arrays, jagged arrays, array of objects

**Object-Oriented Programming**
- Classes and objects
- Constructors
- `static` keyword and static methods
- Encapsulation (getters & setters)
- Method overloading

**Strings**
- `String` class methods
- `StringBuffer` for mutable strings
