## 🚀 Getting Started

### Prerequisites
```
✓ Java JDK 8 or higher
✓ Any IDE (IntelliJ IDEA, Eclipse, VS Code) or terminal
✓ Basic command-line knowledge
```

### Quick Start

1. **Clone the repository:**
```bash
git clone https://github.com/DAlgoSculptor/Complete-Java.git
cd Complete-Java
```

2. **Navigate to any module:**
```bash
cd 01_Basics
```

3. **Compile & Run:**
```bash
# Compile
javac Hello.java

# Execute
java Hello
```
